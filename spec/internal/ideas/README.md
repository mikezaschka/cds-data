# Ideas

Low-commitment scratch surface for ideas that are not yet requirements or ADRs. Created by the [`/brainstorm`](../../../.claude/commands/brainstorm.md) workflow.

## Statuses

| Status      | Meaning                                                                         |
| ----------- | ------------------------------------------------------------------------------- |
| `Exploring` | Being thought about. Not committed to the roadmap.                              |
| `Promoted`  | Graduated to a requirement row or an ADR. `Promoted to:` points at the target.  |
| `Dropped`   | Considered and rejected. `Why dropped` section explains the decision.           |

## Template

See the template at the bottom of [`/brainstorm`](../../../.claude/commands/brainstorm.md#phase-4--capture).

## Why keep dropped ideas?

So the next person who has the same idea finds the prior exploration and its reasoning, instead of re-doing the work. Files are cheap; institutional memory isn't.
